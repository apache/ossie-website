Honeydew

Honeydew actively supports Apache Ossie (Incubating) and its open, vendor-neutral specification. Its semantic layer is YAML-based and git-native, and converts bidirectionally with Ossie so metrics, attributes and relationships stay portable across BI tools, AI agents and warehouses.

Saiku

Saiku is an open-source semantic layer that lets BI users, Excel, and AI agents query Ossie semantic models without writing SQL.

  • Ossie AI Query API Typed REST and MCP surface to list, describe, and query Ossie models, with self-correcting validation errors so agents never write SQL. Documentation →
  • Natural-language ask over Ossie Ask a question in plain language and Saiku composes a governed Ossie query the model cannot turn into free-form SQL. Documentation →
  • Saiku on GitHub Open-source Mondrian and Calcite semantic layer with dashboards, Excel and XMLA, and MCP for agents. View on GitHub →

Snowflake

Snowflake is committed to keeping Semantic Views and other semantic context interoperable with Apache Ossie.

  • Export to Ossie Convert any Snowflake Semantic View to an Ossie YAML file. Documentation →
  • Import from Ossie Create a Snowflake Semantic View from an Ossie YAML file. Documentation →
